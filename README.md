# Aahin - Data-Driven E-Commerce Platform 🛒

Aahin is a responsive, feature-rich e-commerce front-end built to demonstrate advanced UI logic and seamless API integration.

## 🚀 Live Demo
[View the Live Site here](https://aahin.vercel.app/)

## ✨ Key Features
- **Dynamic Product Loading:** Fetches real-time data using the **DummyJSON API**.
- **Smart Filtering:** Category-based navigation for Electronics, Fashion, and more.
- **Checkout Engine:** Includes a shipping validation system and real-time total price calculations (Subtotal - Discount + Delivery).
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop views.

## 🛠️ Tech Stack
- **Language:** JavaScript (ES6+)
- **Styling:** CSS3 (Custom Flexbox & Grid layouts)
- **Deployment:** Vercel

## 📖 What I Learned
During this project, I mastered handling **Asynchronous JavaScript** (using `fetch` and `.then()`) and managing application state without a heavy framework. It also sharpened my skills in CSS layout debugging.
